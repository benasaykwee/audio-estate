Where it stands

PALLBEARER is six days old. In that time it went from an argument about whether Trilian could be cloned to a 37-parameter physically modelled bass with a C++ twin that matches its JavaScript source bit-for-bit across 13,335 checks, a plugin that compiles against real JUCE headers, and a place in the estate repository.

Two things it does not have. It has never been built into a loadable plugin, because until this morning its CI died 27 seconds into every run. And it has one open fault in the sound: String Coupling turns the instrument into a self-sustaining drone above roughly a third of its range.

The road so far

16 August · morning
v0.1 — the founding decision
Trilian is 34 GB and 21,000 samples of instruments nobody here owns. MODO Bass reaches the same place from physics, which is what this estate already ships. Waveguide, dispersion, pickup combs, body resonance, and the fingering brain. 27 parameters, 120 assertions, worst tuning error 0.089 cents.
16 August · evening
v0.2 — full estate member, same day
The C++ twin, the parity gate, deterministic humanisation on a portable xorshift, the attack-layer renderer that made all three paths audible, fret buzz, three-mode body, articulations. 9,095 parity checks, 11 byte-stable baselines, 86,648 fuzz cases. Writing the C++ found a bug the JS harness had missed.
17 August
v0.3 — ten more solo items
Sympathetic coupling through a bridge bus, hand momentum, pickup coil resonance, the JUCE plugin body, the WAV sample loader that made hybrid and sampled paths live in the browser, the CPU cost gate. 37 parameters, 188 assertions, 13,335 parity checks. Both translation units compiled clean, first try.
17–20 August
The silent stall
Zero files in version control. The workflow existed, the allowlist admitted it, and the sources were never committed — so the macOS build job did not fail, it was never asked. A stale .git/index.lock then froze the whole estate for 29 hours, because the folder mount denies unlink.
21 August
Into the ground
Committed at last, grouped by project, after every gate in four projects was run green. THE VIEWING audit measured the coupling fault. You pushed.
22 August · today
CI unblocked
The LAW 1 guard had two faults: an architecture-blind control that could never be false on x86-64, and a compile failure that read as success. Both fixed and both proved. Both plugin translation units compile clean against pinned JUCE 7.0.12 locally. The next run reaches the macOS job for the first time.

Connectivity — inside the estate

What PALLBEARER shares, what it deliberately refuses, and where its audio goes.

PALLBEARER's own edges shared arithmetic shared dynamics deliberate refusal adjacent, unconnected

The refusal is the interesting edge. Three of the four estate DSP projects consume shared/necrodynamics. PALLBEARER does not, and that was a decision rather than an omission: an instrument that grows its own compressor ends up with two compressors in the chain and no way to reason about either. It renders, and hands the result to the tools built to shape it.

Connectivity — the world outside

Everything PALLBEARER already speaks to, everything it is about to, and the two commercial instruments it was measured against.

The dashed red box is where the risk lives. auval instantiates the plugin, renders audio, ramps automation, and checks that it correctly refuses an illegal buffer size. For PALLBEARER it will also exercise MIDI input, because you are the estate's first aumu rather than an aufx. AUTOPSY, CASKET and RIGOR have all passed through validation without a single note event between them. That surface has never been tested in a host, only in a harness.

The one open fault

String Coupling self-oscillates. Above roughly 0.30 to 0.42 depending on how many strings the tuning has, a single plucked note stops decaying, turns around, and climbs to the soft clipper's ceiling where it sits at a flat +4.1 dB forever. That is not a loud note; it is an oscillator held still by a saturator.

The cause is one missing divisor: the coupling bus is the raw sum of every other string's bridge output, so loop gain scales with string count. Multiply each measured threshold by (N − 1) and the three numbers collapse to 1.26, 1.36 and 1.35. Normalising by the number of contributing strings should move the threshold to about 1.3 for every tuning, which is outside the control's own range, and would make the parameter mean the same thing on a four-string as on a six.

Nothing caught it because peak-bounded is not stable. A drone pinned at the ceiling has no NaN, never throws, and never exceeds 1.6, so it is the best-behaved signal in the fuzz corpus. Full working in THE_VIEWING.html.

The next five things — yours, not mine

These need your machine, your ears, your money or your judgement. I cannot do any of them from here.

  1. Push, and watch the run reach macOS15 min
    cd ~/Desktop/CLAUDE && git push origin main. The LAW 1 fix is committed and waiting. This is the first run that can reach plugin-macos, and whichever way it goes it is the most informative fifteen minutes available to this project. If it fails, save the full log before GitHub truncates it.
  2. Install the artifact and run auval20 min
    Download pallbearer-plugins-macos, and remember Safari may auto-unzip it to the Desktop rather than Downloads. Then the step that actually matters: xattr -dr com.apple.quarantine on both bundles. Right-click-Open is for apps and will not substitute. Then auval -v aumu Pbrr Basy. You want AU VALIDATION SUCCEEDED on the last line.
  3. Play it from the P-155 in Logic and tell me what is wrong with itan hour
    Every number in this report is a measurement. Not one of them is a judgement about whether it sounds like a bass. You are the only one who can say whether the attack is right, whether the fingering brain picks the string a player would, and whether the slap style is embarrassing. That report is worth more to me than any gate.
  4. Decide the Apple Developer ID questionmoney, not code
    These builds are runner-signed, not notarised. They install on your machine after the xattr dance; a stranger's machine would refuse them. That gates any distribution at all, free or paid, and it is $99/year plus paperwork rather than anything I can write. It is worth settling before the licensing question, because the answer changes what licensing even means.
  5. Say what String Coupling is forfive minutes
    I know how to make it stable. I do not know what you want it to do at 100%. Should the top of the dial be "a lot of sympathetic ring," or should it be the unhinged drone it currently is, kept deliberately and relabelled? Both are defensible. The fix is different depending on the answer, so tell me before I pick.

The next ten things — mine, no input needed

Ordered by what I would do first. Everything here is inside PALLBEARER/ and provable by a gate before you ever see it.

  1. Normalise the coupling injection and kill the oscillator
    Divide by the number of contributing strings. JS first, mirror to PallbearerCore.h, re-emit parity, then re-bless the eleven baselines deliberately and say so in the commit, because they should all move and a silent re-blessing is how a project loses its own history.
  2. Build the stability gate that would have caught it
    Pluck once, sweep couple across its range against every tuning, assert the last window is quieter than the window at one second. Fifteen lines. It is the only item on this list that prevents the fault class rather than the fault, and the same assertion is missing from RIGOR and NECROPHONE.
  3. Harden the MIDI surface before auval gets to it
    The one place I expect the validator to bite. All-notes-off, sustain pedal, pitch bend, overlapping note-ons on one string, note-off for a note never started, and a note-on at the very last sample of a block. Every one of those is a harness test I can write and gate without a host.
  4. Pin couple: 0 in the tuning test and gate the value, not the limit
    Restores the honest 0.088 cents, and replaces "under 2 cents" with "within a hair of the recorded figure" so the next 115% drift is loud instead of silent.
  5. Stereo out
    Both channels are currently identical. A bass with two pickups at different positions along the string has an obvious and physically motivated answer, and it costs nothing at the sample level.
  6. Oversample the drive stage
    It aliases at high settings. The Interchange warns that oversampler taps are the first thing the compiler wants to fuse, so this one arrives with a parity re-run at all three optimisation levels rather than a claim.
  7. Make the attack layer survive a session save
    State carries a version stamp but not the audio, so a hybrid or sampled patch reloads silent. A file path would break the moment the file moved, which is worse, so the audio goes in the state itself.
  8. Extract a real patch library
    Nine presets currently live as a literal inside the HTML, which means the plugin cannot see them. Same data, one file, both faces, and a gate that every preset loads and renders without clipping.
  9. Correct the three stale claims and regenerate THE CARRY
    The README says 0.085 cents where the harness prints 0.184, and says coupling costs 2.6× where the gate's own baseline says 4.27×. The second figure has already escaped into the project notes, which is how a wrong number becomes a fact.
  10. Draft the bespoke editor
    Last deliberately. Generic sliders plus a neck diagram is the honest placeholder, and writing a rich JUCE editor is the one item on this list a compiler-less session can spend itself on for nothing. Once a binary exists, that changes.
